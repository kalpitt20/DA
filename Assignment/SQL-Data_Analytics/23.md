Dataset: Zomato Bangalore Restaurants – Kaggle Kaggle+ Goal As a Data Analyst for Zomato Bangalore, use SQL to help business teams answer key questions around restaurant performance, pricing, ratings, customer preferences, and market segmentation. The outcome should guide marketing, partnerships, and strategic expansion decisions.

1.
Write an SQL query to find the top 5 highest-rated restaurants in Koramangala, showing their name, average rating, and number of votes.
<b>Ans<b>
SELECT 
    name,rating,votes
FROM zomato_bangalore_restaurants
WHERE location LIKE '%Koramangala%'
ORDER BY rating DESC, votes DESC
LIMIT 5;

3.
Write an SQL query to calculate the average cost for two people for each restaurant type (such as 'Cafe', 'Casual Dining', etc.) and order the results from most to least expensive.

<b>Ans<b>
SELECT rest_type,ROUND(AVG(approx_cost_for_two), 2) AS avg_cost_for_two
FROM zomato_bangalore_restaurants
WHERE approx_cost_for_two IS NOT NULL 
AND rest_type IS NOT NULL
GROUP BY rest_type
ORDER BY avg_cost_for_two DESC;

4.
Find all restaurants that have a rating below 3.0 but more than 200 votes, and suggest a possible marketing action for these based on your findings.

<b>Ans<b>
SELECT restaurant_id,name,location,rating,votes,approx_cost_for_two
FROM zomato_bangalore_restaurants
WHERE rating < 3.0 
AND votes > 200
ORDER BY votes DESC;

5.
Use ChatGPT to generate an SQL query that segments restaurants into three market categories: 'Budget' (cost for two < 500), 'Mid-range' (500-1500), and 'Premium' (>1500). Test and run the query on your dataset, and paste the working query in your submission.

<b>Ans<b>

SELECT 
    CASE 
        WHEN approx_cost_for_two < 500 THEN 'Budget'
        WHEN approx_cost_for_two BETWEEN 500 AND 1500 THEN 'Mid-range'
        ELSE 'Premium'
    END AS market_segment,
    COUNT(restaurant_id) AS total_restaurants,
    ROUND(AVG(rating), 2) AS avg_segment_rating,
    SUM(votes) AS total_segment_votes
FROM zomato_bangalore_restaurants
WHERE approx_cost_for_two IS NOT NULL
GROUP BY 
    CASE 
        WHEN approx_cost_for_two < 500 THEN 'Budget'
        WHEN approx_cost_for_two BETWEEN 500 AND 1500 THEN 'Mid-range'
        ELSE 'Premium'
    END
ORDER BY 
    MIN(approx_cost_for_two) ASC;
