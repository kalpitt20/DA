1.
Write an SQL query using CONCAT to combine first_name and last_name columns from a users table into a single full_name column and display the result.

<b>Ans<b>
SELECT CONCAT(first_name, ' ', last_name) AS full_name 
FROM users;

<b>Output<b>
This query combines the first_name and last_name columns into a single string separated by a space, labeled as full_name.

2.
Given a table called playlists with a column song_title, write a query to display all song titles in uppercase using the UPPER function.

<b>Ans<b>

SELECT UPPER(song_title) AS uppercase_song_title 
FROM playlists;

<b>Output<b>

This query converts every song title in the playlists table to uppercase letters.

3.
You have a table food_items with a column item_code that sometimes contains extra spaces at the beginning or end. Write an SQL query to select item_code values after removing all leading and trailing spaces using TRIM.

<b>Ans<b>

SELECT TRIM(item_code) AS clean_item_code 
FROM food_items;

<b>Output<b>

This query removes all leading and trailing whitespace characters (spaces, tabs, newlines) from the item_code values in the food_items table.

4.
In a table called movies, the column imdb_id contains codes like 'tt1234567'. Write a query to extract just the numeric part (the last 7 characters) using RIGHT and display it as movie_number.

<b>Ans<b>

SELECT RIGHT(imdb_id, 7) AS movie_number 
FROM movies;

<b>Output<b>

This query extracts the last 7 characters from the right side of the imdb_id column for each row in the movies table.

5.
A products table has a column sku_code where some entries use dashes (e.g. 'MOB-123-XY'). Write an SQL query to replace all dashes '-' with underscores '_' in sku_code using the REPLACE function and display the updated codes

<b>Ans<b>

SELECT REPLACE(sku_code, '-', '_') AS updated_sku_code 
FROM products;

<b>Output<b>

This query replaces every occurrence of a hyphen (-) with an underscore (_) in the sku_code column for all rows in the products table.
