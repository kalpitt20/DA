1.
Create a table called Orders with columns: order_id, user_id, order_amount, and app_name (e.g., 'Zomato', 'Swiggy', 'Flipkart'). Insert at least 10 sample records with different users and apps. Write an SQL query using the OVER() function to display each order's amount along with the total order amount for all orders.

<b>Ans<b>
SELECT order_id,user_id,app_name,order_amount,SUM(order_amount) OVER() AS total_all_orders
FROM Orders;

<b>Output<b>
This query returns all 10 individual rows from the Orders table, alongside a new column (total_all_orders) showing the grand sum of all orders (6800.00) repeated across every row

2.
Using the Orders table, write an SQL query to show each user's order_id, order_amount, and the average order_amount for that user using the OVER(PARTITION BY user_id) clause.

<b>Ans<b>
SELECT order_id,user_id,order_amount,ROUND(AVG(order_amount) OVER(PARTITION BY user_id), 2) AS user_avg_order_amount
FROM Orders;
<b>Output<b>

|order_id|user_id|order_amount|user_avg_order_amount|
|--------|-------|------------|---------------------|
|1	     |1	     |450.00      |     	650.00      |
|2	     |1	     |300.00	  |         650.00      | 
|3       |1      |	1200.00   | 	650.00          |

3.
Suppose you have a table called Playlist with columns: song_id, user_id, and duration_sec. Write an SQL query to display each song's duration, and the total duration of songs added by each user using SUM(duration_sec) OVER(PARTITION BY user_id).
<b>Ans<b>

SELECT 
song_id,user_id,duration_sec,SUM(duration_sec) OVER(PARTITION BY user_id) AS total_user_playlist_duration
FROM Playlist;

<b>Output<b>
This query calculates the total duration of all songs in each user's playlist and displays that grand total alongside every individual song entry.

4.
Given a table named MovieRatings with columns: rating_id, user_id, movie_name, and rating (1-5), write an SQL query to show each rating, the average rating per movie, and the difference between the user's rating and the movie's average rating using window functions.

<b>Ans<b>

SELECT 
    rating_id,user_id,movie_name,rating AS user_rating,
    ROUND(AVG(rating) OVER(PARTITION BY movie_name), 2) AS movie_avg_rating,
    ROUND(rating - AVG(rating) OVER(PARTITION BY movie_name), 2) AS rating_difference
FROM MovieRatings;

<b>Output<b>

This query calculates the overall average rating for each movie and compares each user's individual rating against that movie's average.
