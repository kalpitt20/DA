1.
Create a SQL view named TopRatedRestaurants that selects the restaurant name, average rating, and total number of reviews from a table of Zomato-style restaurant reviews, showing only restaurants with an average rating above 4.0.

<b>Ans<b>
CREATE VIEW TopRatedRestaurants AS
SELECT 
    restaurant_name,AVG(rating) AS avg_rating,COUNT(review_id) AS total_reviews
FROM restaurant_reviews
GROUP BY restaurant_name
HAVING AVG(rating) > 4.0;

<b>Output<b>

This query creates a virtual table named TopRatedRestaurants that dynamically summarizes and filters the restaurant_reviews table to show only restaurants with an average rating higher than 4.0.

2.
Update the TopRatedRestaurants view to also include the city column from the original restaurants table by joining the relevant tables.

<b>Ans<b>

CREATE OR REPLACE VIEW TopRatedRestaurants AS
SELECT r.restaurant_name,r.city,AVG(rev.rating) AS avg_rating,COUNT(rev.review_id) AS total_reviews
FROM restaurants r
INNER JOIN restaurant_reviews rev ON r.restaurant_id = rev.restaurant_id
GROUP BY r.restaurant_name, r.city
HAVING AVG(rev.rating) > 4.0;

<b>Output<b>

This query creates a virtual table named TopRatedRestaurants that dynamically summarizes and filters the restaurant_reviews table to show only restaurants with an average rating higher than 4.0.

4.
Create a view called DailyOrderSummary that shows, for each date, the total number of food orders and the total revenue from a Swiggy-style orders table. Ensure the view only includes dates from the last 30 days.

<b>Ans<b>

CREATE VIEW DailyOrderSummary AS
SELECT order_date,COUNT(order_id) AS total_orders,SUM(total_amount) AS total_revenue
FROM swiggy_orders
WHERE order_date >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY)
GROUP BY order_date;

<b>Output<b>

This query creates a virtual table named DailyOrderSummary that tracks daily total order volumes and total revenue from swiggy_orders over the last 30 days.

 Best Practices for Dashboard Analytics Views

1.Use Explicit Column Aliases for Clean Dashboard Metrics

Example: Use SUM(amount) AS total_sales_inr rather than leaving raw function names like SUM(amount) in a Flipkart sales view.

2.Filter Heavy Datasets Inside the View Definition

Example: Apply WHERE order_date >= '2026-01-01' inside a Flipkart order reporting view to prevent loading multi-year historical logs into Power BI or Tableau.

3.Avoid Using SELECT * in View Definitions

Example: Explicitly specify SELECT order_id, user_id, order_status in Flipkart customer views so future database schema changes do not break dashboard connections.
