Indexing & Query Optimization Topics: Why queries become slow Index types EXPLAIN PLAN Avoiding full table scans 

1.
Run a SELECT query on a large 'orders' table (at least 10,000 rows) to find all orders for a specific user_id and measure the query execution time.

<b>Ans<b>

SELECT * FROM orders WHERE user_id = 4521;

<b>Output<b>

This query retrieves all columns for every record in the orders table matching a specific user_id. Because user_id is unindexed, MySQL performs a Full Table Scan.

2.
Create an index on the user_id column of the 'orders' table and re-run the same SELECT query to measure the new execution time.

<b>Ans<b>

-- 1. Create B-Tree index on user_id
CREATE INDEX idx_user_id ON orders(user_id);

-- 2. Re-run identical SELECT query
SELECT * 
FROM orders 
WHERE user_id = 4521;

<b>Output<b>

With the B-Tree index created, MySQL no longer scans the entire table line-by-line. Instead, it uses an Index Range Scan (or Index Lookup), dropping query execution time from seconds to milliseconds.

3.
Use the EXPLAIN PLAN command to analyze how your SELECT query runs before and after adding the index, and write down the key differences you observe in the output.

<b>Ans<b>

EXPLAIN SELECT * FROM orders WHERE user_id = 4521;

<b>Output<b>

The EXPLAIN keyword acts as a diagnostic tool. Prefixing any SELECT statement with EXPLAIN instructs MySQL to return its execution plan—showing how the query optimizer intends to execute the query without actually running it.

4.
Write a query for a 'products' table that avoids a full table scan by using an index on the 'category' column to fetch all products in a specific category.

<b>Ans<b>

-- 1. Create index on category
CREATE INDEX idx_products_category ON products(category);

-- 2. Execute targeted indexed lookup
SELECT product_id, product_name, price, category
FROM products
WHERE category = 'Electronics';

<b>Output<b>

This script creates a single-column B-Tree index on the category field and then uses it to quickly extract all product details belonging strictly to the 'Electronics' category.
