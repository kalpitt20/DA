1.
Write an SQL query using the WITH clause to create a temporary result set called TopArtists that selects the top 3 most-followed artists from a table SpotifyArtists (columns: artist_id, name, followers), then select all rows from TopArtists.

<b>Ans<b>
WITH TopArtists AS (
    SELECT artist_id, name, followers
    FROM SpotifyArtists
    ORDER BY followers DESC
    LIMIT 3
)
SELECT * FROM TopArtists; 

<b>Output<b>
The query will return a table with 3 rows, representing the top 3 most followed artists in the SpotifyArtists table, sorted in descending order of their follower counts.

2.
Using a table named FlipkartOrders (columns: order_id, user_id, order_date, total_amount), write a query with a CTE called MonthlyTotals that calculates the total sales amount for each month in 2023, then select the month with the highest total sales from MonthlyTotals.

<b>Ans<b>
WITH MonthlyTotals AS (
    SELECT 
        DATE_FORMAT(order_date, '%Y-%m') AS sales_month,
        SUM(total_amount) AS total_sales
    FROM FlipkartOrders
    WHERE order_date >= '2023-01-01' AND order_date <= '2023-12-31'
    GROUP BY DATE_FORMAT(order_date, '%Y-%m')
)
SELECT sales_month, total_sales
FROM MonthlyTotals
ORDER BY total_sales DESC
LIMIT 1;

<b>Output<b>
This query will return a single row representing the highest sales month of 2023 from the FlipkartOrders table.

|-----------|-----------|
|2023-09    |5cr        |

3.
Create a recursive CTE to generate a list of dates for the next 7 days starting from today in a table called CalendarDays (columns: day_date).

<b>Ans<b>
WITH RECURSIVE CalendarDays AS (
    -- Anchor Member: Start date (Today)
    SELECT CURRENT_DATE() AS day_date
    
    UNION ALL
    
    -- Recursive Member: Increment by 1 day up to 6 iterations
    SELECT DATE_ADD(day_date, INTERVAL 1 DAY)
    FROM CalendarDays
    WHERE day_date < DATE_ADD(CURRENT_DATE(), INTERVAL 6 DAY)
)
SELECT day_date FROM CalendarDays;

4.
Given a table called ZomatoRestaurants (columns: id, name, city, rating), use a CTE to find the average rating for each city, then select all restaurants in cities where the average rating is above 4.0.
<b>Ans<b>
WITH CityAverageRatings AS (
    SELECT 
        city,
        AVG(rating) AS avg_city_rating
    FROM ZomatoRestaurants
    GROUP BY city
    HAVING AVG(rating) > 4.0
)
SELECT zr.id,zr.name,zr.city,zr.rating
FROM ZomatoRestaurants zr 
INNER JOIN CityAverageRatings car ON zr.city = car.city;
<b>Output<b>
This query returns all individual restaurants located in high-performing cities where the overall citywide average rating is strictly greater than 4.0.
5.
Use ChatGPT or Copilot to help you write an SQL query with a CTE that, given a table IPLMatches (columns: match_id, team, runs, match_year), calculates the total runs scored by each team in 2023 and lists only teams with more than 2000 runs.
<b>Ans<b>
WITH TeamRuns2023 AS (
    SELECT team,SUM(runs) AS total_runs FROM IPLMatches
    WHERE match_year = 2023
    GROUP BY team
)
SELECT team, total_runs FROM TeamRuns2023 
WHERE total_runs > 2000
ORDER BY total_runs DESC;
<b>Output<b>
This query returns a ranked list of IPL teams that scored more than 2,000 total runs in the 2023 season, ordered from highest total runs to lowest.
