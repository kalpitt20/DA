CASE WHEN (Conditional Logic) Topics: CASE WHEN ELSE END Categorizing data on the fly Binning values
1.
Write an SQL query using CASE WHEN to classify orders in a 'FoodOrders' table as 'Small', 'Medium', or 'Large' based on the total_amount: 'Small' for less than 300, 'Medium' for 300 to 999, and 'Large' for 1000 and above.

<b>Ans<b>
SELECT order_id,user_id,total_amount,
    CASE 
    WHEN total_amount < 300 THEN 'Small'
    WHEN total_amount BETWEEN 300 AND 999 THEN 'Medium'
    ELSE 'Large'
    END AS order_size
FROM FoodOrders;

<b>Output<b>
This query categorizes each food order into a size bucket—Small, Medium, or Large—based on its monetary value using conditional logic.

2.
Given a 'Movies' table with a 'rating' column (out of 10), write an SQL query that adds a new column 'popularity' which shows 'Blockbuster' for ratings 8 and above, 'Hit' for 5 to 7.9, and 'Average' for below 5 using CASE WHEN ELSE END.

<b>Ans<b>
SELECT movie_id,title,rating,
    CASE 
    WHEN rating >= 8.0 THEN 'Blockbuster'
    WHEN rating >= 5.0 AND rating < 8.0 THEN 'Hit'
    ELSE 'Average'
    END AS popularity
FROM Movies;

<b>Output<b>

This query evaluates each movie's rating and assigns it a performance label—Blockbuster, Hit, or Average—based on specified threshold ranges.

3.
For a 'FlipkartProducts' table with a 'price' column, write an SQL query to create a 'price_category' column that bins prices as 'Budget' (below 500), 'Standard' (500 to 2000), and 'Premium' (above 2000) using CASE WHEN.

<b>Ans<b>

SELECT product_id,product_name,price,
    CASE 
    WHEN price < 500 THEN 'Budget'
    WHEN price BETWEEN 500 AND 2000 THEN 'Standard'
    ELSE 'Premium'
    END AS price_category
FROM FlipkartProducts;

<b>Output<b>

This query classifies products into three price tier categories—Budget, Standard, or Premium—based on their cost.

4.
Write an SQL query for a 'SpotifyTracks' table that uses CASE WHEN to assign a 'duration_label' column: 'Short' for tracks under 180 seconds, 'Medium' for 180-300 seconds, and 'Long' for over 300 seconds.

<b>Ans<b>

SELECT track_id,track_name,duration_sec,
    CASE 
    WHEN duration_sec < 180 THEN 'Short'
    WHEN duration_sec BETWEEN 180 AND 300 THEN 'Medium'
    ELSE 'Long'
    END AS duration_label
FROM SpotifyTracks;

<b>Output<b>

This query categorizes music tracks by their length in seconds into three duration tiers—Short, Medium, or Long.
