1.
Write an SQL query using the NOW() function to display the current date and time as 'CurrentDateTime' in your result set.

<b>Ans<b>

SELECT NOW() AS CurrentDateTime;

<b>Output<b>

This query returns the current system date and time timestamp when executed on the MySQL server.

2.
Suppose you have a table called Orders with a column order_date (DATE type). Write a query to display each order's order_date, the year, month, and day as separate columns using YEAR(), MONTH(), and DAY().

<b>Ans<b>

SELECT order_date,
    YEAR(order_date) AS order_year,
    MONTH(order_date) AS order_month,
    DAY(order_date) AS order_day
FROM Orders;

<b>Output<b>

This query extracts and separates the date components—year, month number, and day of the month—from the order_date column for every row in the Orders table.

3.
Imagine you are building a feature like Zomato's order delivery estimate. Given a table Deliveries with a column delivery_date, write a query to show delivery_date and a new column expected_pickup_date which is 2 days before delivery_date using DATE_SUB().

<b>Ans<b>

SELECT delivery_date,DATE_SUB(delivery_date, INTERVAL 2 DAY) AS expected_pickup_date
FROM Deliveries;

<b>Output<b>

This query subtracts 2 days from the delivery_date column for every row in the Deliveries table to compute the expected_pickup_date.

4.
You have a table called Subscriptions with columns user_id, start_date, and end_date. Write a query to display user_id, start_date, end_date, and the total number of days of each subscription using DATEDIFF().

<b>Ans<b>

SELECT user_id,start_date,end_date,
DATEDIFF(end_date, start_date) AS subscription_days
FROM Subscriptions;

<b>Output<b>

This query calculates the total duration (in days) between the start and end dates of each subscription.

5.
Create an SQL query for a table named AppLogins (columns: user_id, last_login_date) to find all users who haven't logged in for more than 30 days from today. Use NOW() and DATEDIFF() in your query.

<b>Ans<b>

SELECT user_id,last_login_date FROM AppLogins
WHERE DATEDIFF(NOW(), last_login_date) > 30;

<b>Output<b>

This query returns the user_id and last_login_date for all users who have not logged in for more than 30 days relative to the current system date and time.
