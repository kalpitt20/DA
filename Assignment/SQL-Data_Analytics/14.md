1.
Given a table Orders with columns (order_id, user_id, order_date, total_amount), write an SQL query using ROW_NUMBER() to assign a unique sequential number to each order per user, ordered by order_date descending.

<b>Ans<b>

SELECT order_id,user_id,order_date,total_amount,
    ROW_NUMBER() OVER(
    PARTITION BY user_id 
    ORDER BY order_date DESC
    ) AS order_sequence
FROM Orders;

<b>Output<b>
This query assigns a sequential rank to each order for every user, ordering them from the most recent purchase to the oldest.

2.
Suppose you have a table called Songs with columns (song_id, artist, streams). Write an SQL query using RANK() to list each song along with its rank based on streams within each artist.

<b>Ans<b>

SELECT song_id,artist,streams,
    RANK() OVER(
    PARTITION BY artist 
    ORDER BY streams DESC
    ) AS stream_rank
FROM Songs;

<b>Output<b>
This query ranks each artist's songs by their stream count in descending order, assigning equal ranks to songs with identical stream counts.

3.
For a table named Movies with columns (movie_id, genre, rating), write an SQL query using DENSE_RANK() to assign a rank to each movie within its genre based on rating, with the highest rating getting rank 1.

<b>Ans<b>
SELECT movie_id,genre,rating,
    DENSE_RANK() OVER(
    PARTITION BY genre 
    ORDER BY rating DESC
    ) AS rating_rank
FROM Movies;

<b>Output<b>
This query ranks movies within each genre based on their rating from highest to lowest, using dense ranking to prevent gaps in sequence numbers after ties.

4.
Imagine a table named Influencers with columns (id, platform, followers). Write an SQL query to display the top 3 influencers per platform using ROW_NUMBER(), showing id, platform, followers, and their row number.

<b>Ans<b>

WITH RankedInfluencers AS (
    SELECT id,platform,followers,
        ROW_NUMBER() OVER(
        PARTITION BY platform 
        ORDER BY followers DESC
        ) AS rank_num
    FROM Influencers
)
SELECT id,platform,followers,rank_num
FROM RankedInfluencers
WHERE rank_num <= 3;

<b>Output<b>
This query returns the top 3 influencers with the highest follower count for each social media platform.
