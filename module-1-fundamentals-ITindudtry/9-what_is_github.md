# What is GitHub?

GitHub is a platform where you can store, manage, and share your code online.

👉 Simple words:
It’s like Google Drive for code, but much more powerful.

🔹 How GitHub Works

You write code on your computer
You upload it to GitHub (called a repository)
You can track changes, update code, or collaborate with others

🔹 Key Terms (Very Important)
Repository (Repo) → A project folder (your code stored online)
Commit → Save changes
Push → Upload code to GitHub
Pull → Download latest code
Branch → Work on new features without affecting main code

🔹 Why GitHub is Used

✅ Backup your code safely
✅ Track every change (version control)
✅ Work with teams
✅ Show your projects (portfolio)
✅ Contribute to open-source projects
