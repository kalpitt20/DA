# 🔹 What is a Web Server?

A web server is a system (software + hardware) that stores websites and delivers them to users when they request them.

👉 Simple:
When you open a website, the web server sends the webpage to your browser.

🔹 How a Web Server Works
You type a URL (like google.com)

Your browser sends a request to the server

The web server processes it

It sends back the website (HTML, CSS, etc.)

Your browser displays it


🔹 Examples of Web Servers
Apache HTTP Server
Nginx
Microsoft IIS


🔹 Types of Web Servers

1. Static Web Server
Sends fixed files
Fast and simple

2. Dynamic Web Server
Generates content using database & backend
Used for apps like login systems


🔹 Why Web Servers are Important

✅ Make websites accessible on internet
✅ Handle user requests
✅ Work 24/7
✅ Manage traffic and data

🔥 Real-Life Example

When you open YouTube:

Your request goes to a web server
Server sends video + page data
You see the website instantly
