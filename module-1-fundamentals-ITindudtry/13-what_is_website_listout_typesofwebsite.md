# 🔹 What is a Website?

A website is a collection of web pages available on the internet under one domain.

👉 Simple:
It’s something you open in a browser like Chrome — for example:

Google
YouTube
Amazon

All of these are websites.

🔹 Types of Websites

1. Static Website
Fixed content (doesn’t change often)
Simple and fast

👉 Example: Basic portfolio website


2. Dynamic Website
Content changes (database-driven)
Interactive

👉 Example: Facebook, YouTube


3. E-commerce Website
Used to buy/sell products

👉 Example: Amazon, Flipkart


4. Blog Website
Articles, posts, tutorials

👉 Example: Tech blogs, news blogs


5. Portfolio Website
Shows personal work, skills

👉 Example: Developer or designer portfolio


6. Business (Corporate) Website
Company information, services

👉 Example: Company homepage


7. Educational Website
Learning content, courses

👉 Example: Online learning platforms


8. Social Media Website
Connect with people

👉 Example: Instagram, Facebook


9. News Website
Latest news and updates

👉 Example: News portals


🔥 Simple Trick to Remember
Static → Simple

Dynamic → Interactive

E-commerce → Selling

Blog → Content

Portfolio → Personal

Social → People
