# what is URL?

URL stands for Uniform Resource Locator.
It’s simply the address of something on the internet.

👉 Just like your home has an address, every webpage or file online has a URL.

🔹 Example of a URL
https://www.google.com


# Take this URL:

https://www.example.com/page

1. https:// → Protocol
Tells how data is transferred
Example: HTTP, HTTPS (secure)
2. www.example.com → Domain Name
The main website name
Easy for humans to remember
3. /page → Path
Specific page or resource on the website

🔹 Simple Understanding
URL = Full address
Domain = Website name
Hosting = Where website is stored

🔥 Real-Life Example

If you search on Google:
URL: https://www.youtube.com/watch?v=xyz
It directly opens a specific video
