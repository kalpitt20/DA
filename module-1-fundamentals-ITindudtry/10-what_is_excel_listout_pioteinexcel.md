# 🔹 What is Excel?

Excel (by Microsoft) is a spreadsheet software used to:

-Store data in rows & columns
-Perform calculations
-Analyze and visualize data

👉 Simple: It’s a tool to manage and analyze data (very important for your data analyst path).

🔹 What is a Pivot Table in Excel?

A Pivot Table is a feature in Excel that helps you:
👉 Summarize, analyze, and organize large data easily
Instead of manually calculating totals, Excel does it instantly.

🔹 How Pivot Table Works

Example:
You have sales data like:
Date
Product
City
Amount

👉 With Pivot Table, you can quickly find:
Total sales per city
Sales per product
Monthly revenue

🔹 Main Parts of Pivot Table
Rows → What you want to show on left side
Columns → Categories across top
Values → Numbers (sum, count, average)
Filters → Filter data easily

🔹 Why Pivot Table is Powerful
✅ Saves time
✅ No formulas needed
✅ Easy to change view
✅ Used in jobs (very important skill)

🔥 Simple Real-Life Example
You have 1000 rows of shop data

👉 Without Pivot:
You calculate manually (time waste)

👉 With Pivot:
2 clicks → total profit by month
