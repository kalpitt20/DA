# 🔹 What is a Browser?

A browser (web browser) is a software application used to access and view websites on the internet.

👉 Simple:
It’s the app you use to open websites.

🔹 Examples of Browsers
Google Chrome
Mozilla Firefox
Microsoft Edge
Safari

🔹 How a Browser Works

You type a URL (like google.com)
Browser sends request to web server
Server sends back data (HTML, CSS, JS)
Browser reads and displays the website

🔹 What a Browser Does

✅ Opens websites
✅ Shows text, images, videos
✅ Runs JavaScript (interactive features)
✅ Saves bookmarks & history
